# 🧮 Calculadora Tradicional & Científica em Python

Uma aplicação completa de calculadora interativa, desenvolvida para rodar via linha de comando (terminal) e também com interface web responsiva.

---

## 🚀 Funcionalidades

- **Operações Básicas:** Adição (+), Subtração (-), Multiplicação (*) e Divisão (/).
- **Suporte Numérico Flexível:** Aceita decimais formatados tanto com vírgula (ex: `10,5`) quanto com ponto (ex: `10.5`).
- **Tratamento de Erros Resiliente:** Proteção contínua contra entradas inválidas (`ValueError`) e divisão por zero (`ZeroDivisionError`) sem derrubar a aplicação.
- **Formatação Inteligente:** Números inteiros são exibidos sem decimais desnecessários e dízimas são arredondadas para até 2 casas decimais.
- **Suíte de Testes Automatizados:** Testes unitários utilizando a biblioteca nativa `unittest`.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Python 3.10+ (seguindo padrões PEP 8 e Clean Code)
- **Interface Web / Applet:** React + TypeScript + Tailwind CSS
